# Bundled fonts

All faces are the hinted static TTFs from the Noto Sans release `NotoSans-v2.015`
(`https://github.com/notofonts/latin-greek-cyrillic/releases/tag/NotoSans-v2.015`,
path `NotoSans/hinted/ttf/`). Licence: SIL Open Font License 1.1, see `OFL.txt`.

- `NotoSans-Regular.ttf`: body text, PDF regular and italic slots.
- `NotoSans-Bold.ttf`: PDF bold and bold italic slots; UI bold.
- `NotoSans-SemiBold.ttf`: UI semibold (panel titles). Not used by the PDF.
